# GameEngine

RenderingLibraryを利用するモジュール型ゲームエンジンSDKです。

## 開発目標

- 描画ライブラリとゲームエンジンの責務分離
- シーンおよびゲームオブジェクト管理
- 入力、物理、オーディオなどのゲーム制作機能
- アセット管理
- 拡張可能なモジュール機構
- プロジェクト単位のモジュール管理とバージョン固定
